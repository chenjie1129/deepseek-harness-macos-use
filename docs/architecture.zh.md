# Agent Note: macOS GUI 与浏览器使用

Status: implemented

[English](architecture.md) | 中文

## 问题

Harness 可以编辑文件并运行 shell 命令，但对于仅通过 macOS GUI 或渲染后的浏览器页面提供功能的应用，它没有明确的能力接缝。如果把桌面控制直接加入一个面向模型的工具，就会在同一个包里混合操作系统执行、浏览器生命周期、视觉提供方配置、循环策略与结果持久性。

## 决策

实现新增由四个包组成的 `macos-use` 家族。专用 GUI 模型服务把截图发送到可配置的 OpenAI 兼容视觉端点，因此 GUI 定位不要求驱动模型接受图片输入。端点、模型、输出上限和凭据引用都是可实时更新的可视化插件设置。P0 在像素观察之外加入语义窗口观察路径：应用与窗口发现、精确窗口截图、扁平化辅助功能元素，以及在新快照或窗口几何变化后过期的不透明元素令牌。

## 能力拆分

- `@deepseek-ai/dsh-macos-use` 负责通过 `ctx.subprocess` 执行脱敏全屏与精确窗口截图、应用／窗口发现、辅助功能状态、System Events 操作、CoreGraphics 指针移动／拖动、应用启动和 AppleScript。
- `@deepseek-ai/dsh-browser-use` 负责一个延迟启动的 Playwright Chromium 页面，并提供选择器、文本、键盘、坐标、拖动和截图操作；实时切换有头／无头模式会在下一次动作前安全重启浏览器。
- `@deepseek-ai/dsh-gui-model` 负责一次独立的截图到动作请求，并校验返回的动作联合类型。
- `@deepseek-ai/dsh-tool-macos-use` 负责面向模型的基础 schema，以及有边界的桌面和浏览器动作循环。

## 安全与持久性

macOS“辅助功能”和“屏幕录制”权限仍由宿主控制。拒绝列表优先于允许列表。全屏截图会遮盖被排除应用的窗口；针对被排除内容的精确窗口截图会直接失败。任意 AppleScript、拖动、破坏性按键和破坏性任务意图可以要求一次性确认。单任务锁、任务总超时、命令超时、显式中止工具和可视化紧急停止共同约束自主控制；这组包不会创建持久权限授权。

截图字节通过 `ctx.attachments` 保存，而驱动模型只接收文本引用，因为其主要适配器拒绝图片工具结果内容。GUI 模型请求与中间决策位于驱动 Session 日志之外。默认开启的展示设置可以把每一步用于定位的截图保存为经过授权的仅 UI 结果内容；最终任务结果仍会保留完成状态、摘要、动作与结果列表以及最终截图引用。存储副本会按当前附件限制进行规范化，但不会改变用于定位的原始像素或动作坐标。

工具包同时具有 Host 与 Client 两个 face。Host 把保留的步骤图片投影到 `tool/result.data.meta.content`；Session Controller 授权这些引用，Session 导出会包含其对象。Client 校验该元数据，通过 Session 附件线路加载图片，并在 keyed `tool.call.toolview` slot 中渲染任务卡。截图被规范化缩小时，任务输出 schema 会接受附件服务提供的可选 `originalDimensions` 元数据。

## 考虑过的替代方案

- **仅使用 shell 控制。** Shell 命令无法可靠观察或操作那些有意义状态只存在于渲染界面的应用。
- **单体插件。** 单个包会耦合浏览器、桌面、提供方、设置、工具 schema 与循环变更，无法独立替换或进行聚焦测试。
- **使用驱动模型视觉能力。** 要求主智能体模型消费截图，会使桌面能力依赖该模型的模态支持，并把大型图片结果放进普通对话历史。

## 验证

聚焦测试覆盖 AppleScript 与原生脚本构造、macOS 服务行为、语义令牌过期、任务协调与中止、GUI 响应解析与请求、浏览器生命周期／操作、策略确认、输出 schema 校验、可视化设置卡注册、授权附件加载，以及有边界的任务循环执行。这些包通过生产 Web 构建和完整 GUI 门禁。干净 profile 的实时 UI 测试还让真实截图经过本地视觉边界，并在第 1 步内联显示其附件。真实第三方提供方凭据仍属于部署检查。

## 结果

产品可以独立组合桌面执行、浏览器执行、GUI 定位和面向模型的工具，同时让驱动模型保持仅文本。所有可调整的 P0 智能体选项都可在插件配置页面的 GUI 模型或 GUI 智能体卡中可视化设置；部署文件仍是可审计表示，但不再是唯一配置方式。这样的拆分增加了明确的安装要求：必须存在 Playwright Chromium，宿主必须拥有操作系统权限。中间 GUI 步骤可在最终结果中观察，也可以选择同时显示其截图，但不是独立持久的 Session 事件。
